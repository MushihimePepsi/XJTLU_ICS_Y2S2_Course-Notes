AI Systems
A Typical Workflow for AI Systems
1. Formulate Problem: Define the problem, establish goals, and 
translate business/research context into a well-defined AI task.
2. Collect Data: Gather relevant, high-quality data, including 
sourcing, cleaning, and preprocessing.
3. Feature Extraction: Identify and select informative attributes 
from raw data for machine learning.
4. Machine Learning: Apply algorithms to train a model, tune 
parameters, and validate performance.
5. System Deployed: Integrate the model into production, monitor, 
and maintain it for real-time use.
Hierarchy of AI Intelligence
• Computation Intelligence: Maps Features to a 
unified Label. Key applications: Classification, Outlier 
Detection.
• Perception Intelligence: Maps Features to 
multiple, non-unified Labels. E.g., Emotion Detection.
• Creative Intelligence: Generates novel content 
beyond pattern matching, augmenting human creativity.
• Universal Intelligence: Hypothetical ability to learn 
any human intellectual task (AGI goal).

Machine Learning vs. Deep learning
9
Machine Learning (ML)
Requires human experts to define features (e.g., "has wheels"). 
The computer then classifies based on this predefined 
checklist. This is called manual feature engineering.
Deep Learning (DL)
Automatically learns features from raw data using a Neural 
Network. It excels at complex tasks like image and speech 
recognition, removing the need for manual feature 
engineering.

The Essence of Neural Networks: It's All About "Guessing"
Y = aX+b
Y = a1X+a2X²+...
Given X=1,Y=2；X=2,Y=3
Method: Use algebra.
Process: With two known points (x1, y1) and 
(x2, y2), set up two equations and solve for the 
unknown variables 'a' and 'b’.
Result: An exact, analytical solution. This is 
the traditional method taught in schools and math 
classes.
Method: Guess and Check (Iterative Refinement).
Process:1. Start with random initial values for 
'a' and 'b'.
2. Calculate the error (the difference between the 
guess and the real value).
3. Use the error to refine the next guess.
4. Repeat this cycle thousands of times.
Result: An approximate, but often very good 
solution. This is how machine learning algorithms often 
work.

The Problem with Early Models: Lack of "Reasoning"
"Parroting" Instead of 
"Thinking"
• Early models excelled at regurgitating information 
and stitching text together, mimicking human 
language without true understanding.
• They failed at executing step-by-step logic and 
were highly prone to "hallucinations"—inventing 
plausible but false facts.
• Critical limitation: They lacked the ability to 
reason, making them unreliable for complex 
problem-solving.
The Rise of Reasoning 
Models (2024)
• Cutting-edge models like OpenAI o1, DeepSeek-
R1, and Kimi-k1.5 are engineered to "think step-by-
step," decomposing problems logically.
• Capabilities expanded to solve complex multi-step 
math problems, write high-quality code, and answer 
advanced scientific questions.
• In rigorous technical evaluations, their proficiency 
now rivals that of a PhD student in specialized STEM 
fields.

DeepSeek's Insight: Reasoning Through RL
DeepSeek showed that complex fine-tuning might not be necessary. 
Instead,pure reinforcement learning (RL)could be the key to teaching 
reasoning.
How it works:The model (agent) attempts to solve problems and 
receives immediate feedback (reward). Through trial and error, it learns to 
reason effectively, experiencing "Aha moments."
Benefits:This method is more resource-efficient than traditional fine-
tuning and develops robust, generalizable reasoning skills that apply across 
different tasks.
Open-Source Commitment:DeepSeek released powerful 
reasoning models that can run on smaller consumer-grade computers, 
democratizing access to advanced AI capabilities.
